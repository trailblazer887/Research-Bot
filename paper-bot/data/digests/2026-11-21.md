1) Neural Memory Orchestration
   问题：HPC 工作负载因 mmap 文件、swap 和分层内存的缺页而停顿，内核启发式预取器在数据依赖的不规则访问流上效果急剧下降。
   核心：用 eBPF 采集缺页序列，由远端推理硬件上的 transformer 预测未来页地址，并在内核侧提前物化页面。
   结果：Hilbert-curve traversal 运行时降低约 35%，dense matrix multiplication 降低约一个数量级，major-fault 计数相应减少。
   与你：它把缺页序列当作可预测信号源，对应水位线问题中“信号从何而来”；但预测的是页地址而非内存压力水位，账本层需自行补足 cgroup 级用量与回收动作的映射。
   读法：泛读｜eBPF, page fault
   https://arxiv.org/abs/2611.23857
